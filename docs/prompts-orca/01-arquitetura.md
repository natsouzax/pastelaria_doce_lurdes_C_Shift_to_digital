# Prompt — agente de arquitetura

Trabalha na branch `architecture-design-flow` do repositório `natsouzax/pastelaria_doce_lurdes_C_Shift_to_digital`. Lê `README.md`, `docs/requisitos.md`, `docs/modelo-dados.md`, `docs/contrato-mvp.md` e os anexos originais do Cliente C se estiverem disponíveis. A equipa escolheu Next.js/TypeScript/Tailwind, API REST com Route Handlers em Node.js, Supabase PostgreSQL/Auth e publicação Vercel. Não substituas esta stack sem justificar e consultar a coordenação.

Objetivo: fechar o contrato técnico mínimo para que backend e frontend possam trabalhar em paralelo. Produz `docs/api.md` com pedidos/respostas, erros e permissões para as rotas de `docs/contrato-mvp.md`; define entidades/colunas e transições de estado, incluindo item individual por bolo, preço por kg, capacidade de seis bolos físicos, sinal e pagamentos simulados. Documenta decisões para lacunas do dossier. Dá prioridade aos sete passos da demo e ao prazo do evento.

Não implementes a aplicação inteira. Se criares subagentes, limita-os a revisão independente do modelo, regras e contrato; integra o resultado nesta branch. Entrega um resumo das decisões, riscos e verificações; faz commit/push na tua branch. Não coloques dados pessoais da equipa nem segredos no GitHub.
