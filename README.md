# Doce Lurdes — gestão de encomendas

Projeto da equipa Lyons para o desafio Shift To Digital 2026. O objetivo é reunir encomendas de uma pastelaria artesanal num único sistema, com regras de prazos, capacidade, sinal, produção e seguimento pelo cliente.

## Estado

Planeamento da arquitetura e dos fluxos. A implementação começa após a definição do contrato de dados e das regras do servidor.

## Fontes e requisitos

Ver [requisitos](docs/requisitos.md) e [decisões de arquitetura](docs/arquitetura.md). Os ficheiros originais do desafio ficam fora deste repositório até ser revista a sua publicação.

## Entrega esperada

Aplicação web com frontend, API REST e MySQL ou PostgreSQL; dados fictícios fornecidos carregados por seed; contas de teste para Gestora e Produção; cliente sem conta com código de seguimento. O README será completado com instruções de instalação, execução e demonstração quando a arquitetura estiver definida.

## Segurança do repositório

Nunca publicar `.env`, credenciais reais, `node_modules` ou dados de contacto da equipa. A configuração de exemplo ficará em `.env.example`.
